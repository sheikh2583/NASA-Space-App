## Goal
Supply real formative user evidence for C06; agent simulation cannot substitute for intended users.

## Steps
1. Use ws6_validation/USER_STUDY.md. Sheikh recruits/contacts participants and obtains consent; no automatic outreach.
2. Observe 3-5 people if feasible, including relevant planning/data practitioners. Record proxy status and raw task counts.
3. Use the current supported interface/brief. Record task time, help, failures and participant explanations of sources, cutoff, missingness and detections.
4. Provide anonymized notes outside Git; never expose participant identities.
5. After prioritized fixes, repeat with a fresh participant where possible and record remaining confusion.

## Done when
Anonymized observations and limitations are supplied for T34/T63. If participants are unavailable, explicitly record that evidence is missing; do not mark an unperformed study done or claim demonstrated impact.
